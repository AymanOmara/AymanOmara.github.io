02 / ABOUT ME

From native iOS to full product delivery.

I'm a Senior Mobile Engineer based in Cairo, Egypt. I started out in native iOS with Swift, then moved into Android and Flutter, and learned ASP.NET Core so I could build the APIs and admin dashboards my apps depend on.

My focus is architecture that stays maintainable: modular Clean Architecture with separate common, domain, data and di packages, BLoC/Cubit state management, typed networking and high unit-test coverage.

I try to unblock teams early. When the NCA backend wasn't ready, I built a mock API so the app could keep moving. I build security in before a penetration test has to find it, and I lay out Arabic screens right-to-left from the start instead of patching them later. I'm looking for a team where I can own mobile architecture and help others ship.

01

Clean Architecture

Layered, testable code that's still easy to change two years later.

02

RTL & localization

Arabic and English apps built RTL from the start.

03

Full product ownership

Design handoff → mobile → API → dashboard → store release.

04

Quality

Unit tests with MockK and bloc_test, coverage tracking, code review.
