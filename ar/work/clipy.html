مدير حافظة لا يغادر جهاز الـ Mac أبدًا.

يحتفظ Clipy بكل ما تنسخه، من نصوص وصور وملفات، ويعيده إليك باختصار واحد أو بسحبة إصبعين. أضاف الإصدار 1.1 لوحات التثبيت والمقتطفات النصية وقائمة اللصق المتتابع والبحث داخل الصور. إنه تطبيق macOS أصلي مبني بـ Swift وSwiftUI وAppKit، وصُمِّم ليعمل دون اتصال بالكامل: لا يُرسَل أي شيء تنسخه إلى أي مكان.

الفكرة

يتذكّر macOS آخر شيء نسخته فقط. أما Clipy فيتذكّر آخر 50 عنصرًا (أو العدد الذي تحدّده) ويعرضها بطاقاتٍ تفهمها بنظرة واحدة: النص، أو معاينة للصورة، أو الملف، مع التطبيق الذي نُسخ منه ووقت نسخه. ابحث، وصفِّ حسب النوع، وثبّت ما تعيد استخدامه، والصق بضغطة رقم.

الجديد في 1.1

  • بطاقات ذكية. يتعرّف التطبيق على الروابط والألوان (مع عيّنة حيّة) وعناوين البريد وأرقام الهاتف والشيفرة (مع تلوين الصياغة)، ولكلٍّ منها تبويب خاص.
  • يحتفظ بالتنسيق. النص المنسوخ من Pages أو Notes أو المتصفح يُلصق بتنسيقه كما هو، و⌥↩ يلصقه نصًا عاديًا.
  • قائمة اللصق المتتابع. أضف البطاقات إلى القائمة بـ ⇧↩، ثم اضغط ⌃⌘V في أي تطبيق لتلصقها واحدة تلو الأخرى، وهذا مفيد عند ملء النماذج.
  • لوحات التثبيت والمقتطفات. اجمع العناصر في تبويبات مسمّاة وملوّنة، واحفظ النصوص التي تلصقها كثيرًا مع المتغيّرات {date} و{time} و{clipboard}.
  • البحث داخل الصور. يقرأ إطار Vision من Apple النص الموجود في لقطات الشاشة المنسوخة على جهازك نفسه، فيصبح قابلًا للبحث. ويفهم البحث أيضًا المرشّحات app: وtype: وdate: وboard:.
  • المعاينة السريعة والتحويلات. مفتاح المسافة يعرض العنصر كاملًا، والنقر بالزر الأيمن يلصقه بأحرف كبيرة أو JSON منسّقًا أو Base64 وغير ذلك.
  • تحكّم أكبر في الخصوصية. اختر تطبيقات لا يُحفظ ما يُنسخ منها أبدًا، واحذف السجل تلقائيًا بعد مدة بين يوم و90 يومًا.
  • إجراءات لتطبيق Shortcuts لجلب عناصر الحافظة والبحث فيها وحفظها من أتمتتك الخاصة.

العمل مع macOS

معظم العمل يقع في المواضع التي يحتاج فيها التطبيق إلى الخروج من نافذته: مراقبة حافظة النظام، والتقاط اختصار في كل التطبيقات، واللصق داخل تطبيق آخر.

private func checkPasteboard() {
    let currentChangeCount = pasteboard.changeCount
    guard currentChangeCount != lastChangeCount else { return }
    lastChangeCount = currentChangeCount

    // Passwords and one-off values are never recorded
    if let types = pasteboard.types, !ignoredTypes.isDisjoint(with: types) { return }

    // Neither is anything copied in an app the user chose to ignore
    let sourceApp = NSWorkspace.shared.frontmostApplication
    if exclusions.isExcluded(bundleID: sourceApp?.bundleIdentifier) { return }

    // Every file of a selection, an image, or text with its RTF/HTML
    guard let content = readContent() else { return }
    onClipboardChanged?(ClipboardCapture(
        content: content,
        sourceAppName: sourceApp?.localizedName,
        sourceBundleID: sourceApp?.bundleIdentifier,
        changeCount: currentChangeCount
    ))
}

  • مراقب NSEvent عام يفتح اللوحة عندما تمرّر للأعلى على بعد 60 نقطة من أسفل الشاشة.
  • اللوحة نافذة بلا إطار ولا تسحب التركيز، فلا يفقد التطبيق الذي ستلصق فيه تركيزه عند فتحها. ونافذة المعاينة السريعة فوقها لا تأخذ التركيز كذلك، فتظل الأسهم والمسافة وEsc تعمل داخل اللوحة.
  • حين يكتب Clipy في الحافظة بنفسه يتذكّر رقم التغيير، فيصعد العنصر القديم الذي تلصقه إلى الأعلى بدلًا من تسجيله مرتين.
  • كتابة ⌘V داخل تطبيق آخر تحتاج إلى إذن تسهيلات الاستخدام (Accessibility) في macOS. يتحقّق Clipy منه بـ CGPreflightPostEventAccess، ويطلبه بـ CGRequestPostEventAccess، ويفتح القسم الصحيح في إعدادات النظام مباشرة إذا رُفض.

البنية

لا يعتمد مدير السجل إلا على بضعة بروتوكولات صغيرة. كل تكامل مع النظام يقف خلف واحد منها، فيمكن استبداله. وهذا بالضبط ما تستخدمه لقطات هذه الصفحة: الواجهات الحقيقية، تغذّيها بدائل في الذاكرة.

من النسخ إلى اللصق

  1. النسختنسخ نصًا أو صورة أو ملفًا في أي تطبيق.
  2. الاكتشافيلاحظ Clipy تغيّر الحافظة، إذ يفحص رقم التغيير مرتين في الثانية.
  3. التصفيةيتجاوز العناصر التي تعلّمها برامج كلمات المرور بأنها مخفية، وكل ما يُنسخ في تطبيق مستثنى.
  4. الحفظتُحسب بصمة الصور وتُرمَّز ويُقرأ النص فيها بعيدًا عن الخيط الرئيسي، والنسخ المكرر يصعد إلى الأعلى بدلًا من أن يتكرر.
  5. الفتح⌘⇧V، أو سحبة بإصبعين عند الحافة السفلية، أو الزر العائم، أو شريط القوائم.
  6. اللصقاختر بطاقة أو اضغط من 1 إلى 9، بالتنسيق أو دونه: يعيد Clipy تنشيط تطبيقك السابق ويكتب ⌘V.

الإعدادات

صارت الإعدادات تتبع أسلوب إعدادات نظام macOS: شريط جانبي بالأقسام ونماذج مجمّعة تتبع الوضع الفاتح أو الداكن ولون التمييز في النظام. يضم قسم عام التشغيل عند تسجيل الدخول وإذن اللصق وحدود السجل، ويسجّل قسم الاختصارات اختصارات عامة جديدة ويعرض مفاتيح اللوحة، ويعرض قسم الخصوصية التطبيقات المستثناة، ويدير قسما المقتطفات ولوحات التثبيت مجموعاتك، ويعرض قسم التخزين ذاكرة الصور المؤقتة ويمسح السجل بعد أن يسألك أولًا.

ومنذ الإصدار 1.1.1 تظهر نافذة الإعدادات أمام التطبيق الذي تعمل فيه عند فتحها من اللوحة، بدلًا من أن تختفي خلفه.
