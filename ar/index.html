02 / نبذة عني

من iOS الأصلي إلى تسليم المنتج كاملًا.

أنا مهندس تطبيقات جوال أول مقيم في القاهرة. بدأت بتطوير iOS الأصلي بلغة Swift، ثم انتقلت إلى أندرويد وFlutter، وتعلّمت ASP.NET Core لأبني واجهات API ولوحات التحكم التي تعتمد عليها تطبيقاتي.

أركّز على معمارية تبقى سهلة الصيانة: Clean Architecture معيارية بحزم منفصلة common وdomain وdata وdi، وإدارة الحالة بـ BLoC/Cubit، وشبكات بأنواع محددة، وتغطية عالية باختبارات الوحدة.

أحاول أن أزيل العوائق عن الفريق مبكرًا. حين لم تكن الواجهة الخلفية لتطبيق NCA جاهزة، بنيت API وهمية ليستمر العمل. أبني الأمان من البداية قبل أن يكتشف اختبار الاختراق الثغرات، وأصمّم الشاشات العربية من اليمين إلى اليسار منذ اليوم الأول بدل ترقيعها لاحقًا. أبحث عن فريق أتولّى فيه معمارية الجوال وأساعد الآخرين على الإطلاق.

01

Clean Architecture

شيفرة بطبقات قابلة للاختبار، تبقى سهلة التعديل بعد عامين.

02

RTL والتعريب

تطبيقات عربية وإنجليزية مبنية من اليمين إلى اليسار منذ البداية.

03

ملكية كاملة للمنتج

من استلام التصميم ← الجوال ← API ← لوحة التحكم ← النشر في المتاجر.

04

الجودة

اختبارات وحدة بـ MockK وbloc_test، ومتابعة التغطية، ومراجعة الشيفرة.
