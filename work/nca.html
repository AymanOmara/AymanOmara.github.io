Shipping an Arabic-first government app before its backend existed.

An employee app for the National Cybersecurity Authority of Saudi Arabia: attendance, leaves, visits and service requests. The production backend was still in development while the app was being built.

The problem

The app had to cover attendance, leave, visit and service-request flows in Arabic first, with English alongside. Sign-in went through Microsoft Azure AD. The production backend was being built at the same time, so the mobile team had no real API to build against.

What I did

  • Top contributor on an eight-person team, with about 45% of 550+ commits.
  • Built features with Cubit for state and Retrofit for typed networking, plus Azure AD sign-in.
  • Built a .NET 8 mock API that mirrors 33 production endpoints, so the team could build and test real flows before the backend was ready.
