CASE STUDY · FULL-STACK E-COMMERCE · FLUTTER + .NET 8

An e-commerce app that reminds you to reorder.

Rahtk is a shopping app with one extra idea: group the products you buy regularly into a reminder, and the app nudges you when it’s time to order again. I built both sides, the Flutter client and the .NET 8 API behind it.

The idea

Many household purchases repeat on a rhythm: coffee every month, filters every few weeks. Rahtk lets a shopper pick several products, give the group a title and an interval in days, and get a push notification when it’s time to reorder, alongside the usual browsing, favourites, cart and checkout.

The mobile app

  • 20 screens: onboarding, sign-up with email OTP verification and password reset, home, categories, product details, favourites, cart, checkout, order history, addresses with location lookup, reminders and a notification centre.
  • One Cubit per screen on separate common, domain, data and di packages, with get_it for wiring.
  • A Dio client that returns a typed Result, and a refresh-token interceptor that holds failed requests during a 401, refreshes the session once, then retries them.
  • Firebase Cloud Messaging for pushes, shown in the foreground with local notifications, in Arabic and English.

The API

  • A .NET 8 solution split into Api, Application, Domain, Contracts, Infrastructure, Shared and an IoC composition root.
  • 32 endpoints across users, products, categories, orders, addresses, payment options and reminders, with ASP.NET Core Identity, JWT access and refresh tokens, and Swagger.
  • EF Core on SQL Server with 11 entities. Product names and descriptions are stored in both languages, and responses are localized from the request’s language.
  • Each reminder is a Hangfire recurring job stored in SQL Server. When it’s due, Firebase Admin sends the push and the API saves it to the user’s notification centre.

Outcome

One developer, both ends of the product: a Flutter client and a layered .NET 8 API that share one idea, reorder reminders, from the form on the phone to the scheduled job and the push that comes back.
