A clipboard manager that never leaves your Mac.

Clipy keeps everything you copy, text, images and files, and brings it back with one shortcut or a swipe. Version 1.1 adds pinboards, snippets, a paste stack and search inside images. It’s a native macOS app in Swift, SwiftUI and AppKit, built to stay fully offline: nothing you copy is sent anywhere.

The idea

macOS remembers one thing you copied. Clipy remembers the last 50 (or up to the limit you set) and shows them as cards you can see at a glance: the text, a preview of the image, or the file, with the app it came from and when. Search, filter by type, pin what you reuse, and paste with a number key.

What’s new in 1.1

  • Smart cards. Links, colors (with a live swatch), emails, phone numbers and code (syntax highlighted) are recognised, and each has its own tab.
  • Rich text is kept. Formatting copied from Pages, Notes or a browser pastes back intact; ⌥↩ pastes plain text instead.
  • Paste stack. Queue cards with ⇧↩, then press ⌃⌘V in any app to paste them one by one, which is handy for filling in forms.
  • Pinboards and snippets. Group items into named, coloured tabs, and save text you paste often with {date}, {time} or {clipboard} placeholders.
  • Search inside images. Apple’s Vision framework reads the text in copied screenshots on your Mac, so you can search for it. Search also understands app:, type:, date: and board: filters.
  • Quick Look and transforms. Space previews the full item; right-click to paste it as UPPERCASE, formatted JSON, Base64 and more.
  • More privacy controls. Choose apps whose copies are never saved, and delete history automatically after 1 to 90 days.
  • Shortcuts app actions to get, search and save clipboard items from your own automations.

Working with macOS

Most of the work is in the places where an app has to reach outside its own window: watching the system clipboard, catching a shortcut in every app, and pasting into someone else’s app.

private func checkPasteboard() {
    let currentChangeCount = pasteboard.changeCount
    guard currentChangeCount != lastChangeCount else { return }
    lastChangeCount = currentChangeCount

    // Passwords and one-off values are never recorded
    if let types = pasteboard.types, !ignoredTypes.isDisjoint(with: types) { return }

    // Neither is anything copied in an app the user chose to ignore
    let sourceApp = NSWorkspace.shared.frontmostApplication
    if exclusions.isExcluded(bundleID: sourceApp?.bundleIdentifier) { return }

    // Every file of a selection, an image, or text with its RTF/HTML
    guard let content = readContent() else { return }
    onClipboardChanged?(ClipboardCapture(
        content: content,
        sourceAppName: sourceApp?.localizedName,
        sourceBundleID: sourceApp?.bundleIdentifier,
        changeCount: currentChangeCount
    ))
}

final class CGEventPasteSimulator: PasteSimulating {
    private let virtualKeyV: CGKeyCode = 0x09

    func simulatePaste() {
        let source = CGEventSource(stateID: .hidSystemState)
        let down = CGEvent(keyboardEventSource: source, virtualKey: virtualKeyV, keyDown: true)
        down?.flags = .maskCommand
        let up = CGEvent(keyboardEventSource: source, virtualKey: virtualKeyV, keyDown: false)
        up?.flags = .maskCommand
        down?.post(tap: .cgSessionEventTap)
        up?.post(tap: .cgSessionEventTap)
    }
}
  • Global shortcuts go through Carbon’s RegisterEventHotKey, which works no matter which app is in front. Both ⌘⇧V and Paste Next can be re-recorded in Settings, and a new shortcut is registered before the old one is released, so a taken combination never leaves you without one.
  • A global NSEvent monitor opens the panel when you scroll up within 60 points of the bottom of the screen.
  • The panel is a borderless, non-activating panel, so opening it doesn’t steal focus from the app you’re about to paste into. The Quick Look window above it can’t become key either, so arrows, Space and Esc keep working in the panel.
  • When Clipy writes to the pasteboard itself, it remembers the change count, so pasting an old item moves it to the top instead of recording a duplicate.
  • Typing ⌘V into another app needs macOS Accessibility permission. Clipy checks it with CGPreflightPostEventAccess, asks with CGRequestPostEventAccess, and links straight to the right System Settings pane if it was declined.

Architecture

The history manager depends only on a few small protocols. Each system integration sits behind one, so it can be swapped out. The screenshots on this page use exactly that: the real views, fed by in-memory fakes.

From copy to paste

  1. CopyYou copy text, an image or a file in any app.
  2. DetectClipy notices the pasteboard changed, checking its change count twice a second.
  3. FilterItems marked concealed by password managers, and anything copied in an ignored app, are skipped.
  4. StoreImages are hashed, encoded and read for text off the main thread; a repeat copy moves to the top instead of duplicating.
  5. Open⌘⇧V, a two-finger swipe at the bottom edge, the pill, or the menu bar.
  6. PastePick a card or press 1–9, with or without formatting: Clipy reactivates your previous app and types ⌘V.

Settings

Settings now follows macOS System Settings: a sidebar of panes and grouped forms that match the system’s light or dark mode and accent colour. General holds launch at login, paste access and history limits; Shortcuts records new global shortcuts and lists the panel’s keys; Privacy lists ignored apps; Snippets and Pinboards manage your collections; Storage shows the image cache and clears history, after asking first.

Download for Mac ↓Source code ↗

Clipy 1.1.1 is a universal app for Apple silicon and Intel Macs and needs macOS 26.4 or later. It isn’t notarized by Apple yet, so the first time you open it, go to System Settings → Privacy & Security and click Open Anyway. Allow it under Accessibility to use auto-paste; if you’re updating from 1.0, switch Clipy off and on again there. Your history is kept. The full steps are on the release page ↗.
