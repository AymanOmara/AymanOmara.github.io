A secure investment app, from eKYC to a clean penetration test.

Felousy is a smart investment platform for iOS and Android: eKYC onboarding with a liveness selfie, investing in funds, orders, a wallet with deposits and withdrawals, and portfolio tracking. I led delivery as the primary developer.

The problem

An investment app handles identity documents, money movement and portfolio data, so security could not be bolted on at the end. It also had to hold up to an independent mobile penetration test.

What I did

  • Led delivery as the primary developer, with about 80% of 700+ commits: 14 feature modules and 75 API endpoints on modular Dart packages with BLoC/Cubit.
  • Built eKYC onboarding with a liveness selfie, funds, orders, wallet deposits and withdrawals, and notifications.
  • Wrote 580 unit tests across the data and domain layers.
  • Set up CI/CD in GitHub Actions, Jenkins and Azure DevOps with dev/prod flavors, obfuscated release builds and Firebase App Distribution.
